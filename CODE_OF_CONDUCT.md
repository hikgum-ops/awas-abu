# Community code of conduct

Awas Abu contributors are expected to be respectful, constructive, and careful
with public-safety information. Disagreement is welcome; harassment,
discrimination, threats, doxxing, and deliberate misinformation are not.

Do not post credentials, private phone numbers, precise visitor locations,
operator identities, or real webhook payloads. Do not use project discussions
to issue unofficial warnings or evacuation instructions.

Maintainers may edit or remove harmful content and temporarily or permanently
restrict participation when necessary to protect contributors or the public.
Security-sensitive reports belong in a private GitHub Security Advisory, as
described in `SECURITY.md`.
